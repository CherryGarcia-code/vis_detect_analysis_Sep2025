# Lick & Learning Analysis Manual

This manual covers the analysis of licking behavior and its neural correlates, including the learning progression analysis.

## 1. Lick Analysis Pipeline
**Script**: `scripts/analysis/lick/batch_run_lick_analysis.py`

**Purpose**:
The central tool for lick-related analysis. It functions in two modes:
1.  **Stats Generation** (`--stats-only`): Computes responsive units.
2.  **Full Report**: Generates heatmaps, rasters, and summary PDFs.

**Standard Workflow**:
```bash
# Step 1: Generate Stats for all sessions in manifest
python scripts/analysis/lick/batch_run_lick_analysis.py \
  --manifest data/BG_046_staging_manifest.csv \
  --pkl-dir data/pkls/BG_046 \
  --out FIGURES/lick/BG_046 \
  --stats-only

# Step 2: (Optional) Generate plots for specific sessions
python scripts/analysis/lick/batch_run_lick_analysis.py ... # without --stats-only
```

## 2. Learning & Evolution Analysis
These scripts require the `lick_responsiveness.csv` files generated by Step 1 above.

### A. Learning Progression (Early/Late FAs)
**Script**: `scripts/analysis/learning/compare_early_late_fa.py`
**Purpose**: Compares "Impulsive" (<3s) vs "Derived" (>3s) False Alarms across Naive/Expert stages.
**Usage**:
```bash
python scripts/analysis/learning/compare_early_late_fa.py \
  --manifest data/BG_046_staging_manifest.csv \
  --stats-root FIGURES/lick/BG_046 \
  --out-dir FIGURES/learning_fa_split
```

### B. FA Neural Stratification
**Script**: `scripts/analysis/lick/plot_fa_neural_stratified.py`
**Purpose**: Stratifies activity by **Single Lick** vs **Multi Lick** events.
**Usage**:
```bash
python scripts/analysis/lick/plot_fa_neural_stratified.py \
  --manifest data/BG_046_staging_manifest.csv \
  --stats-root FIGURES/lick/BG_046 \
  --out FIGURES/lick_stratified
```

### C. Chronological Progression
**Script**: `scripts/analysis/lick/plot_chronological_progression.py`
**Purpose**: Scatter plot of lick responsiveness magnitude vs. Date.

## 3. Single Session Scripts (Underlying/Helpers)
These are typically called by the batch runner but can be used standalone for debugging.

*   `scripts/analysis/lick/find_lick_responsive_neurons.py`: Core logic for determining significance.
*   `scripts/analysis/lick/run_lick_analysis_pipeline.py`: Driver for processing a single session.
*   `scripts/analysis/lick/plot_lick_heatmap.py`: Generates the sorted neural heatmap.
*   `scripts/analysis/lick/plot_lick_raster.py`: Generates trial-by-trial rasters aligned to licks.
