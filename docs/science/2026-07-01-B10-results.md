# B10 — Impulsivity kernel across learning: results (2026-07-01)

Branch `feature/impulsivity-kernel`. Subjects BG_046 + BG_039 (DMS), BG_031 (VMS).
Spec: `docs/superpowers/specs/2026-07-01-B10-impulsivity-kernel-learning-design.md`.
**Late-FA convention:** impulsivity analyses use self-timed FAs (latency ≥
`FA_RT_SPLIT` = 3.0 s; early FAs are reflexive) — keeps ~66% of FAs.

## Verdict in one line
A **controlled near-null** on the impulsivity kernel plus a **methods-clean neural
motor-ramp** finding, and one **real (small) real-time-tracking positive** (lag matches
the cells' pulse latency; sustained>transient; engagement modulation unresolved).
Consistent with the N1/B9 pattern (rigorous negatives + clean controls).

## 1. Behavioral impulsivity kernel — WEAK (Fig B10.1, B10.3)
FA-triggered baseline log2-TF minus time-in-trial-matched withhold, late FAs,
n-matched Naive-vs-Expert, 3 mice pooled + per-subject.
- Impulsive licks are preceded by only a **small (~0.03–0.05 log2 ≈ 2–3 %) upward
  TF deflection** peaking ~0.5–0.6 s before the lick; CIs largely span zero.
- **No clean Naive→Expert sharpening**; **no StimSens-vs-Impulsive difference**
  (both states show the same weak kernel — the hypothesized dissociation is absent).
- **Interpretation:** in this task, early licks are largely **internally / urge-
  driven, not triggered by mistaking baseline fluctuations for a change** —
  impulsivity here is not mainly a sensory distractor-rejection failure.
- **Caveat:** raw reverse-correlation (STA) is the *blunt anchor*; Orsolic's
  faithful method (regularized multi-lag lick-hazard regression) was **not run**,
  so "weak" is fair for the STA but not the last word.

## 2. Neural impulsivity kernel — a MOTOR/GAIN ramp, not sensory (Fig B10.2)
Signed TF-responsive population signal (`Σ sign_i·z_i`, `sign = sign(c1_r_log2)`),
FA-vs-withhold, with the **stimulus-matched sensory-vs-gain decomposition** — the
methodological highlight.
- The pre-FA population signal is a **gain/motor ramp** toward the lick, **larger in
  Naive in DMS** (0.77→0.51 z Naive→Expert); the stimulus-matched control shows
  the **sensory component is flat near zero** — the ramp is NOT stimulus-driven.
  (VMS shows NO Naive>Expert ramp: 0.165→0.244 post the date-fix; the earlier
  "VMS 0.44" rested on a single Naive session — see Corrections.)
- **Reproduces N1** (pre-self-timed-lick striatal signals are motor, not evidence)
  and, crucially, the control *prevents* mistaking the ramp for sensory encoding.

## 3. Real-time TF tracking — POSITIVE (Fig tracking)
Does the TF-responsive population signal track the *momentary* baseline log2-TF?
(Smoothed to the ~250 ms integration timescale; baseline-only, stimulus-referenced
→ leakage-safe. Window extended to 1.0 s; 95% bootstrap-over-session CIs.)
- **YES:** the responsive-cell curve rises with lag and **CI-separates from both a
  trial-shuffle null and a non-responsive control** — DMS peak r ≈ 0.018 (lag
  **~0.60 s**, after extending the window past the old 0.5 s truncation), VMS
  r ≈ 0.034 (lag ~0.45 s). Both peaks match the cells' **independent registry
  pulse-kernel peak** (median ~0.40 s) → cross-validated slow (~integration) latency.
- **Transient vs sustained** (registry `kernel_fwhm`): **sustained responders track
  SIGNIFICANTLY better than transient** in both regions (VMS 0.039 vs 0.022; DMS 0.029 vs
  0.014). Paired within-session Wilcoxon: DMS p=0.002 (15/18), VMS p=0.015 (18/24),
  pooled p=5e-5 (33/42). The firmest positive here.
- **Engagement gating — NOT established:** session-level CIs overlap AND the paired
  within-session test is n.s. (DMS p=0.85; VMS p=0.055 weak trend; pooled p=0.16). The
  earlier "strongly gated / ≈0 when disengaged" was **per-trial pseudoreplication**.
  Verdict: unresolved (at most a weak VMS trend).
- **Caveat:** small absolute fidelity (few TF cells/session, a small 50 ms stimulus).

## Controls & limitations (project-wide honesty)
- No video for BG mice → the behavioral kernel is "stimulus history preceding
  impulsive licks," not pure sensory evidence.
- VMS is n=1 region; DMS-Naive has only 1 TF-responsive cell (BG_046) → DMS-Naive
  neural claims are pooled-population-only, not per-cell.
- `region_bank_confirmed` is False registry-wide → pooling by subject, region
  provisional. Lag axis is "time before recorded lick" (no calibrated hardware delay).
- Nulls were pre-registered as reportable.
