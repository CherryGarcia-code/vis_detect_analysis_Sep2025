# User-Defined Behavioral State Labeler — design assets

Presentation-ready mockups for the human-in-the-loop behavioral-state labeling/tagging system
(an alternative to the GLM-HMM that follows where the experimenter draws states by eye).

## Files
- **`design_mockups.html`** — self-contained, single-file deck. Open in any browser (double-click /
  `file://`), no server required. Three interactive sections (data model, go-vs-catch labeler,
  change-size shading toggle) plus the locked design decisions. **Print to PDF** for slides
  (Ctrl/Cmd-P → Save as PDF); the `@media print` rules lay it out cleanly.

## Status
